---
name: setup
description: Однократная настройка автоматического подключения Бакса с сохранением команды codex, проверка и отключение интеграции.
---

Используй при просьбе настроить автоматическое подключение или устранить расхождение
терминала с AppServer после смены аккаунта. Не применяй при каждой сессии.

Найди `bootstrap.py` относительно этого навыка: `../../bootstrap.py`.
Команды запускай как массив аргументов или с корректным shell quoting путей.

1. Выполни `python3 <bootstrap.py> setup` без `--apply`. Это проверяет CLI, оболочку,
   показывает точный файл и блок; не меняет конфигурацию. Поддержаны Codex >=0.166,
   POSIX, zsh и интерактивный bash. Для bash login-shell проверь, что профиль
   пользователя уже читает `.bashrc`; если нет, не обещай автоматический запуск.
2. Объясни: функция `codex` в файле оболочки направит интерактивный запуск в общий
   локальный AppServer. `exec`, `plugin`, справка и другие служебные команды останутся
   нативными. Процессы, модель, разрешения, регистрация и вход не меняются.
   Получи согласие на конкретную правку, если оно ещё не дано в текущем разговоре.
3. После согласия выполни ту же команду с `--apply`. Конфликты с существующей
   функцией/alias и ручными правками не обходи. Не переписывай весь shell config.
4. Для первого подключения проекта используй навык `connect`; ключ принимает
   штатный `bax_connect`. Не читай сохранённые регистрации и не переноси токены.
5. Пользователь открывает новый терминал и запускает обычный `codex`. Это переход
   после однократной настройки, а не требование на каждый запуск. Уже работающий
   standalone разговор не переносится и не останавливается автоматически.
6. Codex просит проверить hooks Бакса через `/hooks`. Не включай bypass trust.
   Если изменился код hook, Codex может запросить проверку снова. Без разрешённых
   hooks автоматическое обнаружение не подтверждено.
7. Проверь `bax_status` точного разговора; не объявляй связь готовой только по
   успешной установке. Hooks регистрируют root startup/resume/fork, оставляют
   выбранный на телефоне разговор; compact и дочерние разговоры не перевыбирают его.
   Явный выбор текущего чата выполняет `bax_attach`.

При диагностике: `python3 <bootstrap.py> doctor --project <cwd> --thread <точный ID>`.
Показывает загруженность и состояние входа выбранного AppServer без секретов.
`notLoaded` не означает, что разговор закрыт во всех процессах.

Отключение по просьбе пользователя: сначала `setup --remove`, затем
`setup --remove --apply`. Удаляется только собственный неизменённый блок.
В открытом терминале функция остаётся до `unset -f codex` или закрытия терминала.
Регистрация, история, фоновые процессы и резервная копия сохраняются.
