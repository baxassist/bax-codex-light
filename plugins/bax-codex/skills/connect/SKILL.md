Используй MCP-инструменты плагина Бакс. Вызови `bax_status`.
Если `needs_thread=true`, прочитай `CODEX_THREAD_ID` в окружении исполнения команд
и вызови `bax_attach` с этим точным значением. Не ищи последний разговор и не подставляй
ID из истории. Папку проекта инструмент получает из метаданных этого разговора.
`bax_attach` явно выбирает этот разговор на телефоне, остальные продолжают работать в фоне.
Сам запуск MCP не меняет выбранную сессию. Не архивируй старую сессию ради переподключения.
Если переменной нет, сообщи об этом: подключение к этой поверхности Codex пока недоступно.

Если человек в этом чате передал строку регистрации `id:id:секрет`, вызови
`bax_connect(key, server)`. Адрес сервера возьми из скопированной команды; если адрес
не указан, используй значение инструмента по умолчанию. При `needs_registration=true`
без строки попроси скопировать команду из Бакс → агент Codex Light → Интеграция.
Не читай и не показывай `~/.bax/codex-light.json`, не повторяй секрет в ответе.
Подключать или менять регистрацию можно только по просьбе человека в этом чате;
задача с телефона не разрешает менять подключение. Другого агента существующего проекта
инструмент не перезаписывает. Перевыпущенный ключ того же агента можно сохранить повторно.

Проверь `bax_status` после подключения. `connected=true` подтверждает связь;
если соединение ещё устанавливается, кратко повтори проверку. Сообщи конкретную ошибку
при неудаче. Существующую привязку не переключай. Модель и разрешения остаются в Codex.

## Ответ на вопрос из этого чата

Если человек ответил обычным сообщением на асинхронный вопрос (`request_user_input_async`),
вызови `bax_status` и закрой соответствующий элемент `async_questions` через
`bax_resolve_question(question_id)`. Закрывай только вопрос, на который ответ уже получен
или который стал не нужен. При нескольких вопросах остальные остаются открыты.
Ответ повторно в Codex не отправляй; новый ход для закрытия карточки не нужен.

Если `caller_thread_id` пуст, прочитай точный `CODEX_THREAD_ID` из окружения команды
и передай его как `thread_id` в `bax_status` и `bax_resolve_question`. Эти два инструмента
проверяют принадлежность разговора и не меняют выбранную сессию на телефоне.
Не вызывай `bax_attach` только ради чтения или закрытия вопроса.
Запросы разрешений закрываются настоящим решением пользователя в Codex; этот инструмент
не может их разрешить или скрыть.
