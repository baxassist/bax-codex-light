# Работа над Bax Codex Light Agent

Самостоятельный Python-пакет. Изменения ограничены этим каталогом.
Общение, документация и пояснения в коде — по-русски.

- Читать README перед изменением транспорта или схем.
- Использовать официальный MCP SDK и `websockets`, без собственных framing/STDIO-парсеров.
- Codex API валидировать через закреплённые типы `openai-codex`.
- Не создавать сессии и не менять модель, sandbox или approval policy при attach.
- Проверять точный thread ID и cwd, без поиска «самой новой» сессии или переключения привязки.
- Не выдавать разрешения автоматически. Запоздалые ответы и чужие события отклонять.
- Тесты используют временные регистрации и локальные имитаторы, не ключи пользователя.
- Не править глобальные конфиги Codex, сервер и iOS Бакса при изменении этого пакета.
- Не публиковать пакет и не создавать remote без отдельного запроса.

Проверки: `uv sync --locked`, `.venv/bin/ruff check plugins tests`,
`.venv/bin/ruff format --check plugins tests`, `.venv/bin/pytest tests -q`.
Сетевые тесты могут требовать разрешение sandbox на loopback.
